# Smart India Hackathon (SIH) 2026 - Project Roadmap & Milestones

## Sprint Breakdown

### Milestone 1: Foundations & Architecture (Week 1)
- [x] Repository modularization: `frontend/`, `backend/`, `ai/`, `data/`, `docs/`, `scripts/`, `tests/`
- [x] Baseline API contracts and schema design (`docs/api-contract.md`)
- [x] Verified heritage datasets for Mumbai, Delhi, Rajasthan, Maharashtra, Kerala

### Milestone 2: Geospatial & Multimodal Routing (Week 2)
- [x] Interactive Leaflet geospatial map with state boundary and destination markers
- [x] Multimodal route calculator (Walking, Metro, Suburban Rail, Taxi, Auto)
- [x] Regulated meter fare estimators and distance benchmarks

### Milestone 3: AI Tourism Assistant & Personalization (Week 3)
- [x] Gemini 2.5 LLM integration with custom heritage prompts
- [x] Contextual conversational memory and suggestions
- [x] Onboarding survey for user travel style, pace, and interests

### Milestone 4: 3D Heritage & Virtual Exploration (Week 4)
- [x] Interactive Three.js 3D monument viewer (Gateway of India, CSMT, Hawa Mahal)
- [x] Orbit controls, wireframe modes, and daytime lighting presets
- [x] Audio-visual narration modal with cultural backgrounds

### Milestone 5: Testing, Hardening & Final Evaluation (Hackathon Finale)
- [x] Unit tests for backend routers and services
- [x] Automated test suites for multimodal routing and fare logic
- [x] Cloud Run containerization and production build pipeline
